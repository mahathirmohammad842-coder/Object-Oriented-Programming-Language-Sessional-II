# Object Oriented Programming Language II Sessional

## Description
A collection of Java-based Object Oriented Programming (OOP) Lab and Sessional projects developed for academic purposes. This repository demonstrates core OOP concepts including inheritance, polymorphism, abstraction, encapsulation, file handling, GUI development with JavaFX, and event-driven programming.

---

## Features
- Java OOP concept implementations
- JavaFX GUI applications
- Calculator and Dashboard projects
- To-Do List application
- Polymorphism and Inheritance examples
- File handling and exception handling
- Clean and modular code structure

---

## Technologies Used
- Java
- JavaFX
- NetBeans IDE
- Git & GitHub

---

## Purpose
This repository is created for practicing and submitting Object Oriented Programming Language II Sessional lab works and projects.
